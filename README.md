# WaterSort AI 🧪

**WaterSort AI** is a Flutter-based color-sorting puzzle game that challenges players to organize colored liquid layers into separate tubes. It features five difficulty levels, randomized puzzle generation, an intelligent AI Hint system, and a premium warm user interface.

The application uses a heuristic-guided search algorithm to find valid moves and help players solve puzzles.

## ✨ Features

- **5 Difficulty Levels:** Progress from Medium to Very Hard.
- **Random Puzzle Generation:** New randomized puzzles are generated for each level.
- **AI Hint System:** Get an intelligent suggestion for your next move.
- **Solvability Verification:** Generated puzzles are checked using the search algorithm.
- **Undo:** Reverse your previous move.
- **Reset:** Restart the current puzzle.
- **Level Selection:** Access unlocked levels.
- **Progress Saving:** Automatically saves unlocked levels using SharedPreferences.
- **Animated Gameplay:** Smooth tube selection and colorful liquid animations.
- **Premium Warm UI:** Ivory backgrounds, amber accents, and glossy colorful tubes.
- **Background Processing:** Puzzle generation and AI search run using Flutter isolates to keep the interface responsive.

## 🎮 How to Play

1. Select a tube containing colored liquid.
2. Select another tube as the destination.
3. You can pour one layer if the destination tube is empty or its top color matches the selected color.
4. Continue sorting until every non-empty tube contains four layers of the same color.
5. Use **Undo**, **Reset**, or **Hint** whenever needed.

## 🧠 AI Algorithm

WaterSort AI uses a **Heuristic-Guided Best-First Search Algorithm** to find a solution path.

### 1. Puzzle Representation

- Each tube is represented as a `List<int>`.
- The complete puzzle board is represented as a `List<List<int>>`.
- Each integer represents a specific color.
- The last element of a tube represents its top layer.

### 2. Heuristic Function

The heuristic estimates how many layers are above the initial consecutive group of the same color in each tube.

The solver uses this estimate to prioritize promising puzzle states.

### 3. Priority Queue

A custom binary min-heap is used to efficiently select the next state with the lowest priority score.

The priority is calculated using:

`priority = (heuristic × 4) + path_cost`

### 4. Duplicate State Detection

A canonical state key is generated by sorting the tube representations. This helps identify equivalent board configurations and prevents unnecessary repeated exploration.

### 5. Solution Search

The solver explores valid moves, stores parent references, and reconstructs the first move of a discovered solution.

The AI Hint feature uses this solver to suggest a move.

**Note:** This is a heuristic-guided best-first search approach. It is A*-like, but it does not guarantee an optimal solution.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Android emulator or physical Android device

### Installation

1. Clone this repository:

```bash
git clone https://github.com/YOUR_USERNAME/watersort-ai.git
```

2. Navigate to the project directory:

```bash
cd watersort_ai_flutter
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```

### Build APK

To generate a release APK:

```bash
flutter build apk --release
```

The generated APK will be available at:

```text
build/app/outputs/flutter-apk/app-release.apk
```
